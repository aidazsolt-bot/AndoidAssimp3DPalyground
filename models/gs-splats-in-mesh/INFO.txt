KHR gaussian + mesh mix — SplatsInMesh — links only
==================================================
This playground folder does **not** redistribute the GLB. Same ZIP as
gs-mesh-in-splats.

Expected file
  SplatsInMesh.glb
  Same splat field [0,10]^3; triangle cube node scale 20 (world [0,20]^3) —
  splats in a corner of a larger mesh (inverse of MeshInSplats).

Where to get it
  https://github.com/user-attachments/files/28266442/gltf-splat-examples-2025-05-26-animation.zip
  https://github.com/KhronosGroup/glTF/issues/2562

If only the mesh is AABB-framed and splats stay raw, the cube looks tiny beside
an off-center splat cloud — that is a host framing bug, not this asset's intent.

Shots (documentation only; model not shipped)
  01_cheap.png   - RenderAssimp desktop Vulkan, Gaussian pipe=Cheap
                   (splatotopoint / ellipsoid-fill billboards; NOT reference quality)
  02_khronos.png - same viewer with --gaussian=khronos (KHR_gaussian_splatting
                   ellipse / Sample-Viewer-style). Prefer this for "how it should look".
